# Decode Labs Internship Tasks

This repository contains the **AI and Machine Learning projects completed during my Decode Labs internship**. The projects demonstrate practical applications of Python, Machine Learning, Computer Vision, Recommendation Systems, and Natural Language Processing.

## 📂 Projects

### Task 1 — AI Chatbot

A basic rule-based AI chatbot developed using Python.

**Key Concepts:**

* User input handling
* Conditional statements
* Loops
* Conversational logic
* String processing



---

### Task 2 — Data Classification Using AI

A supervised machine learning project focused on classifying data using a machine learning model.

**Key Concepts:**

* Dataset handling
* Data preprocessing
* Train/test split
* Model training
* Classification
* Prediction
* Accuracy evaluation



---

### Task 3 — AI Book Recommendation System

A recommendation system that suggests books based on user preferences and book information.

**Key Concepts:**

* User preferences
* Genre matching
* Recommendation logic
* Ratings
* Matching/scoring
* Top recommendations



---

### Task 4 — AI Image Recognition

An image recognition project using a **pre-trained Vision Transformer (ViT)** model to identify objects in images.

**Key Concepts:**

* Computer Vision
* Pre-trained AI models
* Image classification
* Vision Transformer (ViT)
* Top-5 predictions
* Confidence scores
* Batch image recognition



---

### Task 5 — AI Spam Email Classifier

An AI-based spam email classification project that analyzes email text and classifies messages as **Spam** or **Not Spam (Ham)**.

**Key Concepts:**

* Natural Language Processing (NLP)
* Text preprocessing
* Feature extraction
* Text classification
* Spam detection
* Model prediction



> **Note:** Task 5 is an optional additional project completed as part of the internship learning process.
